# Flight-Analyzer
Flight Analyzer — A data-driven project using SQL and Power BI to analyze flight performance, revenue, and uncover patterns through data visualization. Features SQL-based data preparation and an interactive Power BI dashboard for actionable insights.

## 🧩 Tools Used
- **SQL** – Data cleaning, transformation, and KPI generation  
- **Power BI** – Interactive dashboards and visualizations  
- **Excel / CSV** – Raw data source

- ## 📊 Power BI Dashboard
**Key Visuals:**
- Top Airlines by On-time Performance   
- Average Delay Duration  
- Flights per Airline
- Revenue by each airline
